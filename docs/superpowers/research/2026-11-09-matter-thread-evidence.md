# Matter/Thread recovery assistant: evidence register

Research date: **2026-11-09**, America/Los_Angeles. Public, read-only research. No accounts, paid APIs, apps, hardware, calls, or diagnostic files were used. A fetched page establishes what its publisher currently says, not that its procedures or APIs work in this project.

## Findings that change the proposal

1. **There is current, firsthand friction, but no prevalence estimate.** An April 14, 2026 Home Assistant user describes intermittent commissioning taking over an hour. A recently retrieved Reddit account describes hours over several days and later reports improvement in that particular installation. These are case reports, not controlled diagnosis or proof of an unsolved universal defect. [R03–R04]
2. **AI-assisted Thread diagnostics already exists.** Thread Doctor competes directly with any claim to analyze mesh snapshots with AI. A useful differentiation hypothesis is guided commissioning before an accessory is successfully paired, correction-aware instructions, retained physical attempts, and a support packet with provenance. That gap needs a side-by-side product test. [R06]
3. **Diagnostic collection is separate from a browser assistant.** Public documentation is accessible; native home/network access, permissions, reachable accessories, compatible tools, and actual export formats are not established. The first demo cannot claim live network inspection. [R01–R02, R05–R09]
4. **The nominal event build window is 90 minutes.** A universal fixer or new native diagnostic application is not credible in that interval. [R10]

## Evidence, licensing and terms policy

- Link to guidance and author short applicability summaries. Publicly readable does not mean redistributable. Do not commit full manuals, store listings, forum dumps, product photos or arbitrary Exa output as a dataset.
- [Home Assistant license page](https://www.home-assistant.io/developers/license/) identifies source code as Apache 2.0; it does not by itself establish the license of every website asset or copied documentation item. Check the exact repository/file before copying. The official TypeSafe skill declares MIT; retain notices if it is later copied.
- Thread Tools' open-source description is insufficient to assume a usable repository/license. Thread Doctor is a proprietary app: user-directed export is a data path, not permission to copy its implementation or buy/redistribute Pro access.
- [Exa Terms](https://exa.ai/assets/Exa_Labs_Terms_of_Service.pdf) govern API use and contain use restrictions; don't infer redistribution rights in retrieved third-party material. Prefer source URLs plus original summaries; review applicable API agreement before building a durable corpus.
- Before future dependency installation, record each exact package version/license and notices. Before any live service use, review current Vapi, Deepgram, TypeSafe, Exa, hosting/tunnel and optional Manus/AdaL terms, retention, training-use controls and pricing in the actual account. No credits or legal permissions are assumed from an event listing.
- [Vapi data flow](https://docs.vapi.ai/security-and-privacy/data-flow) explains provider processing and distinguishes operational logs from user call artifacts. Application deletion cannot promise deletion from every provider. The guessed retention-document URL was inaccessible; account-specific retention remains a gate, not a verified zero-retention claim.
- Diagnostic imports are **off** until a known exporter/version schema and local allowlist/redaction adapter have been validated. No public issue attachment or household log is consent to model processing. Create synthetic fixtures with documented assumptions; do not scrape private logs.

## What the research does not establish

No recovered physical setup; no supported live import format; no read access to a real Thread network; no accurate arbitrary-device catalog; no measured latency/cost; no user demand or willingness to pay; no all-competitor survey; no sponsor API performance comparison; no event admission. These remain explicit validation tasks in the design and conditional plan.
